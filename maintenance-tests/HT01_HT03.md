# Kiểm thử HT01 và HT03

Chạy từ MyDogNet khi SQL Server local đã Healthy. Cấu hình kết nối riêng ở BackEnd/appsettings.Local.json được Git bỏ qua. Không chạy vào production. Harness chỉ chấp nhận SQL loopback và tạo database mới có tiền tố MyDogNetMaintenanceAfter_; dùng FakeCloud thay dịch vụ ảnh thật.

```bash
python3 maintenance-tests/run-publication.py --output /tmp/mydognet-ht-api
python3 maintenance-tests/run.py
cd front-end
npm ci
npx vitest run
VITE_API_URL=/api npm run build
```

Bộ API mới có16 kịch bản dùng SQL thật. Frontend có19 ca HT01/HT03 mới và12 ca hồi quy HC03/HC04/HT02; Axios được mock, editor được cô lập ở ca publication. Luồng Quill thật cần kiểm tra bằng trình duyệt như báo cáo. BackEnd.Tests nhắm net10.0, không chạy được với SDK6 hiện tại; không tính vào số ca đạt.

## UI sau bảo trì

Terminal thứ nhất từ repo:

```bash
python3 maintenance-tests/run-publication.py --serve --output /tmp/mydognet-ht-ui
```

Terminal thứ hai tại front-end:

```bash
VITE_API_URL=/api npm run build
npx vite preview --config vite.sandbox.config.js --port 5175 --strictPort
```

Mở localhost:5175/admin-signin-80820508, dùng tài khoản fixture của Runner.cs (Admin maintadmin, Editor editorA/editorB). Đây là tài khoản dùng riêng trong database thử; không dùng mật khẩu thật. Mỗi lần khởi động helper tạo DB mới và JWT key mới, cần đăng nhập lại.

Luồng xác nhận: tạo nháp, lọc nháp, preview và public404, mở editor publish, mở public đếm1, reload đếm2, preview vẫn2, withdraw và reload public404. API kiểm tra sai chủ/khách riêng. Khi host/proxy còn chạy:

```bash
python3 maintenance-tests/check-publication-proxy.py --output /tmp/mydognet-ht-proxy
```

## Chuẩn bị bản trước sửa để so sánh

Snapshot bị Git bỏ qua. Chạy một lần vào thư mục snapshot trống:

```bash
mkdir -p .local/maintenance/ht01_ht03/baseline
git archive ca6d16452998d197a707abb5ec9e9df556931664 | tar -x -C .local/maintenance/ht01_ht03/baseline
cp maintenance-tests/Runner.cs maintenance-tests/PublicationChecks.cs .local/maintenance/ht01_ht03/baseline/maintenance-tests/
ln -s "$PWD/front-end/node_modules" .local/maintenance/ht01_ht03/baseline/front-end/node_modules
python3 maintenance-tests/run-publication.py --baseline --output /tmp/mydognet-ht-before
```

Baseline ca6d164 có constructor MVC mơ hồ. Runner chỉ khi MAINTENANCE_BASELINE_DI=true đăng ký constructor hai tham số để quan sát chức năng còn thiếu; không sửa product source baseline. Phải công khai điều kiện này khi sử dụng kết quả trước/sau. Baseline nguyên trạng đã được ghi nhận lỗi trong log đầu.

Để xem UI baseline dùng --baseline --serve, copy cấu hình vite.sandbox.config.js từ front-end hiện tại sang front-end của snapshot, build với VITE_API_URL=/api rồi chạy SANDBOX_API_PORT=5190 npx vite preview --config vite.sandbox.config.js --port 5174 --strictPort tại đó.

CSDL thử và log được giữ để đối soát; không tự xóa database local thật. Các cấu hình private trong .local có khóa kết nối/JWT; không đưa lên Git hoặc báo cáo. Không dùng các kết quả local để kết luận CDN Vercel, Cloudinary thật hoặc điện thoại thật đã đạt.
